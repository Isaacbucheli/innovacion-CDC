# Íconos de servicio Azure

Este directorio contiene íconos de servicio de Azure utilizados para representar tipos de recursos en la Plataforma CDC.

## Origen

Los íconos provienen del pack oficial **Azure Architecture Icons V21** disponible en https://learn.microsoft.com/azure/architecture/icons.

Microsoft permite el uso de estos íconos para representar y describir los servicios y productos de Azure. Se incluye el archivo `Microsoft_Terms_of_Use.pdf` que contiene los términos de uso completos.

## Contenido

Este directorio incluye un subconjunto de 31 íconos seleccionados según el inventario de servicios Azure y el flujo de novedades de la Plataforma CDC. Cada ícono tiene un nombre en kebab-case que corresponde a su servicio Azure.
